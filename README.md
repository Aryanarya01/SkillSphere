  # SkillSphere 🚀

SkillSphere is a full-stack freelancing marketplace built using the MERN Stack where clients can post jobs, freelancers can send proposals, chat in realtime, and showcase their portfolio projects.

## ✨ Features

- JWT Authentication & Role-Based Access
- Client & Freelancer Dashboards
- Job Posting & Proposal System
- Realtime Chat with Socket.IO
- Notifications System
- Freelancer Portfolio Projects
- Reviews & Ratings
- Admin Dashboard
- Responsive UI

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Redux Toolkit
- Tailwind CSS
- Socket.IO Client

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- Socket.IO
- JWT Authentication
- Multer
